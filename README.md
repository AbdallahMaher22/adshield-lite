# حاجب الإعلانات الخفيف (AdShield Lite)

تطبيق أندرويد خفيف بيحجب إعلانات كل التطبيقات المثبتة على الجهاز، عن طريق فلترة استعلامات DNS محليًا (نفس الفكرة اللي بيشتغل بيها AdGuard/DNS66)، من غير ما يمرر باقي حركة الإنترنت على أي سيرفر خارجي.

## إزاي بيشتغل
- التطبيق بيفتح VPN محلي على الجهاز (VpnService)، لكنه بيحجز بس عنوان الـ DNS، مش كل حركة الإنترنت.
- كل استعلام DNS بيتفحص ضد قائمة نطاقات إعلانات/تتبع معروفة (`app/src/main/res/raw/blocklist.txt`).
- لو النطاق محجوب: بيترجع رد فوري بعنوان `0.0.0.0` فيمنع تحميل الإعلان.
- لو مش محجوب: بيتمرر لسيرفر DNS حقيقي (Cloudflare 1.1.1.1) ويترجع الرد زي ما هو.
- عشان كده الحل خفيف وسريع ومفيهوش أي معالجة لحركة البيانات نفسها، بس فلترة أسماء النطاقات.

## بناء ملف APK من خلال GitHub (بدون Android Studio)
1. ارفع محتوى المجلد ده كامل على مستودع GitHub جديد.
2. المستودع فيه ملف جاهز: `.github/workflows/build.yml` بيشغل GitHub Actions تلقائيًا مع أي push.
3. من تبويب **Actions** في المستودع، هتلاقي الـ workflow اسمه **Build APK** بيشتغل، استنى لحد ما يخلص (بياخد كام دقيقة).
4. لما يخلص، افتح الـ run وهتلاقي في أسفل الصفحة قسم **Artifacts** فيه ملف اسمه `adshield-lite-debug-apk` — ده ملف الـ APK جاهز للتنزيل.
5. نزّل الملف، فك الضغط عنه (بييجي داخل ملف zip من GitHub)، وهتلاقي `app-debug.apk`.
6. انقله للموبايل وثبّته (لازم تفعّل "السماح بتثبيت من مصادر غير معروفة" لمتصفحك أو مدير الملفات).

## أول تشغيل
- افتح التطبيق واضغط "تشغيل حجب الإعلانات".
- هيظهرلك تنبيه من أندرويد بيطلب إذن الاتصال عبر VPN — اضغط "موافق/OK".
- هيظهر إشعار ثابت يوضح إن الحجب شغال (ده طبيعي وضروري لأي تطبيق VPN في أندرويد).

## خاصية "خاص بـ eFootball™"
خاصية منفصلة (متوقفة افتراضيًا) بتستخدم ملف قواعد جاهز لتقليل اللاج في لعبة eFootball:
- بتحجب سيرفرات AWS Load Balancer اللي بتتغير باستمرار وبتوجّه الاتصال لسيرفرات بعيدة/بطيئة.
- بتوجّه سيرفر اللعبة الرئيسي (`pes22-game.cs.konami.net`) لعنوان IP ثابت محدد مسبقًا بدل ما النظام يختار سيرفر بعيد تلقائيًا.

**طريقة الاستخدام:**
1. من الشاشة الرئيسية، اضغط زرار "⚙️ خاص بـ eFootball™".
2. فعّل الخاصية بالسويتش.
3. من قائمة التطبيقات المثبتة، حدد تطبيق (أو أكتر) عايز تطبق عليه القاعدة دي بس (مثلاً eFootball نفسها).
4. لو الحماية شغالة بالفعل وقتها، وقّفها وشغّلها تاني عشان التغيير ياخد مفعوله.

**ملاحظة مهمة:** تحديد تطبيق معين ("خاص بتطبيق كذا") متاح على أندرويد 10 (API 29) فأحدث فقط، لأن أندرويد الأقدم مايوفرش وسيلة رسمية لمعرفة أي تطبيق بعت طلب الشبكة. على النسخ الأقدم، تفعيل الخاصية هيطبقها بشكل عام على كل الأجهزة.

قواعد eFootball موجودة في: `app/src/main/assets/efootball_no_lag.json` — تقدر تعدّل فيها (تضيف/تشيل حجب أو توجيه) وترفع تعديلك على GitHub وهيتبني APK جديد تلقائيًا.

## تحديث/إضافة نطاقات محجوبة
لو عايز تزود القائمة، عدّل الملف:
```
app/src/main/java/com/abdallahmaher/adshield/../../res/raw/blocklist.txt
```
وضيف اسم النطاق في سطر منفصل، وارفع تعديلك على GitHub — الـ Actions هيبني نسخة APK جديدة تلقائيًا.

## ملاحظات مهمة
- الحل ده بيحجب على مستوى النظام كله (كل التطبيقات)، لأن أندرويد بيوجّه استعلامات DNS بتاعة كل التطبيقات على الـ VPN بمجرد ما يتفعل.
- بعض التطبيقات (خصوصًا اللي بتستخدم DNS-over-HTTPS مدمج زي بعض متصفحات كروم/فايرفوكس) ممكن تتخطى الفلترة أحيانًا؛ ده قيد معروف في كل حلول حجب الإعلانات المعتمدة على DNS، مش عيب في الكود.
- التطبيق ده لا يرسل أي بيانات لأي سيرفر تابع لجهة التطبيق نفسه؛ الاستعلامات غير المحجوبة بتتحول مباشرة لسيرفر DNS عام (Cloudflare).
